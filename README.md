# Mini Piano — Arduino & Wokwi

An Arduino-based electronic piano project that uses push buttons to trigger musical notes through a buzzer. The circuit is designed and tested using the Wokwi simulator.

## Project Overview

The Mini Piano maps individual push buttons to musical notes. Pressing a button triggers the corresponding tone through the buzzer, allowing the user to play simple melodies.

## Components

- Arduino Uno
- 17 push buttons
- Piezo buzzer
- Wokwi simulator

## Project Files

| File | Description |
|---|---|
| `MINI- PIANO.ino` | Arduino program |
| `diagram.json` | Circuit layout and connections |
| `pitches.h` | Musical note frequency definitions |
| `wokwi.toml` | Wokwi CLI configuration |
| `mini-piano.png` | Circuit screenshot |

## Keyboard Controls

The simulated buttons are assigned keyboard keys in the Wokwi diagram. Refer to `diagram.json` for the exact key assignments.

## Running the Project

1. Open the project in Wokwi.
2. Start the simulation.
3. Use the configured keyboard keys or click the simulated buttons to play notes.
